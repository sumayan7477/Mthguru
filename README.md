## 📖 Overview

**MathGuru Academy** is a full-stack educational web application developed to support online mathematics learning. The platform combines a modern frontend, backend APIs, database management, and online payment integration to deliver a seamless digital educational experience.

It focuses on improving the learning experience, simplifying access to educational resources, and providing a maintainable architecture for future growth.

> 🌐 **Live Website:** [https://mathguru.academy/](https://mathguru.academy/)

## 🚀 Getting Started

Follow the steps below to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone <your-repository-url>
cd Mathguru
```

### 2️⃣ Set Up the Frontend

```bash
cd frontend
npm install
npm run dev
```

> 💡 **Note:** Replace `frontend` with the actual frontend directory name if your repository uses a different structure.

### 3️⃣ Set Up the Backend

Open the ASP.NET Core API project in Visual Studio, or navigate to its directory:

```bash
dotnet restore
dotnet build
dotnet run
```

### 4️⃣ Configure the Database

- Configure the **Microsoft SQL Server** connection string.
- Apply the required database migrations or SQL scripts.
- Ensure the backend can successfully connect to the database.

### 5️⃣ Configure Payment Integration

Set up the required **SSLCommerz** credentials and environment settings before testing payment functionality.

> ⚠️ **Security Notice:** Never commit secret keys, credentials, or production configuration files to GitHub.
